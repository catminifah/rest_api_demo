This project is a study-based Flutter application focusing on how to fetch and display data from an API. The app is designed as an article posting platform, where each post includes the following features:

- Displays individual articles fetched from an API

- Ability to translate articles into English

- Share article content

- Text-to-speech support for translated articles

- Copy article content to clipboard

- Save articles as PDF files into the device’s Downloads folder

- Developed and tested on Android devices
